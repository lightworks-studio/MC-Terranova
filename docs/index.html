Install

Terranova runs on Minecraft 1.21.1 with Forge. Java 21 or newer is required.

Get a launcher

We recommend Prism Launcher, but any Modrinth-compatible launcher works for the .mrpack.

Import the pack

Drag the downloaded .mrpack or .zip file into your launcher, or use Add Instance → Import and select the file.

Launch

Give the instance 5 GB or more of RAM, then hit Play. Updates can be applied by re-importing a newer build.





Auto-Update Instance (Prism Launcher) | Advanced Features

Adding your Own Mods (advanced)

Prefer to add other mods? Replace the startup command on the Prism Instance with the following:

"$INST_JAVA" -jar "$INST_MC_DIR/packInstaller.jar" -sm -shc -u https://raw.githubusercontent.com/Lightning323/MC-Terranova/main/pack/pack.toml
